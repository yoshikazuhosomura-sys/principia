p 進 BSD — 異常素点の L 関数の一つの係数から、階数と Ш の p 部分を曲線ごとに読む

BSD 予想（バーチ・スウィンナートン=ダイヤー予想）は、クレイ数学研究所が 2000 年に掲げた七つのミレニアム懸賞問題の一つです（公式の問題ページ）。楕円曲線の有理点の多さ（階数）と、テイト–シャファレヴィッチ群 Ш という測りにくい群の位数が、L 関数という解析的な量から読める、と予想します。この記事は、その p 進版——Mazur・Tate・Teitelbaum が 1986 年に定式化した予想——を、一つの奇素数 p の側から見た記録です。既知の定理を組み合わせると、ある仮定の下で、p 進 L 関数の係数を一つ計算するだけで、その曲線の階数と Ш の p 部分が決まる場合があります。その組み立てと、予想の数値での照合を並べます。BSD 予想そのものは、どの形でも扱っていません。

何の問題か — p 進 BSD 予想は、p 進 L 関数 Lp(E, T) の主係数を、p 進レギュレーター Regp・玉河数・Ш の位数で書く等式です。

何を組み立てたか — 奇素数 p が良通常で ap ≡ 1 (mod p)（異常素点）、E[p] が既約、ある q ∥ N で p ∤ ordq(Δmin)（仮定 H）のとき、Kato の割り切りと Skinner–Urban の等号を一本の連鎖にしました。

曲線ごとの結論 — 独立な有理点が二つあり、玉河数の積が p で割れず、計算した T2 の係数 c2 が p で割れなければ、rank E(Q) = 2・Ш(E/Q)[p∞] = 0・vp(Regp) = 0 です。4,343 箱に当てました。

照合 — 予想の最初の桁が 5,180/5,180、二桁目が 398/398。Ш の p 部分を L の側から読む照合が階数 1 で 41/41、階数 2・p = 3・Шan = 9 の三例で 3/3（付値と最初の桁）。

言わないこと — BSD 予想そのもの、仮定 H の外、p = 2。照合の Шan は複素 BSD 予想の予言値で、三つの例は一つずつでは検定力を持ちません。

01

この問題は何か — 複素の BSD と p 進の BSD

E/Q を楕円曲線、N をその導手、r = rank E(Q) とします。複素の BSD 予想は、L(E, s) の s = 1 での零の位数が r に等しく、主係数が

L(r)(E, 1)/r! = ΩE · ∏ℓ cℓ · #Ш(E/Q) · Reg∞ / (#E(Q)tors)2

で与えられる、と予想します（cℓ は玉河数、Reg∞ は Néron–Tate の高さの行列式）。解析的階数が 0 か 1 の曲線では階数の部分は定理で、Ш が有限であることも分かっています。階数 2 以上では、Ш が有限であることすら一般には知られていません。既知

p 進版では、L 関数を p 進の側に置き換えます。p を良通常の素数（p ∤ N で ap が p 進単数）とし、α を x2 − apx + p の単数根とします。Mazur–Tate–Teitelbaum の p 進 L 関数を、1 + T = (1 + p)s の変数で

Lp(E, T) = Σj≥0 cj Tj

と書きます。予想（Stein–Wuthrich の形、Néron 周期で正規化）は、零の位数が r で、主係数が

Lp*(E, 0) = εp · ∏ℓ cℓ · #Ш(E/Q) · Regγ / (#E(Q)tors)2, εp = (1 − 1/α)2, Regγ = Regp / logp(1 + p)r

となる、というものです。Regp は円分 p 進高さ対（Mazur–Tate の σ 関数で作るもの）の行列式です。予想は単数倍まででなく等式で、原典（Mazur–Tate–Teitelbaum 1986, II §10）でもそう書かれています。既知

この記事が見るのは 異常素点——ap ≡ 1 (mod p)（p ≥ 7 では #E(Fp) = p と同じ）——です。ここでは εp の付値がちょうど 2 になり、Regp は p 整とは限りません（負の付値を持ちえます）。Regp の付値が還元のどんな局所的な条件で決まるかは、論文の本体（§3）の主題です（論文の紹介）。この記事はその外側、L 関数の側を扱います。

階数 2・ap = 1・自明な捩れの曲線では、予想は割らずに書くと

c2 = ω · n · #Ш(E/Q) · U · Regp, ω = ΩE/Ω+ ∈ {1, 2}, n = ∏ℓ cℓ, U ≡ 1 + 5p (mod p2)

という Qp の中の等式になります（Ω+ は PARI/GP の周期 E.omega[1]）。紙（予想の言明からの換算）

02

仮定 H の下で、曲線ごとの結論にする道

仮定 H が、Galois 像の仮定の代わりをする仕組み

Kato の整の割り切り（Thm 17.4(3)）は、そのままの言明では「Galois 像が SL2(Zp) を含む」ことを仮定します。Kato の本文を追うと、この仮定が効くのは Thm 12.5(4) だけで（§17.13）、その証明（§13.14）は三つのことを使います。仮定 H はそれを一つずつ別の形で与えます。既知（言明は原典）紙（読み合わせ）

c2 ≡ Σj=0p−1 C(j, 2) · Sj (mod p), Sj = Σa=1p−1 [ω(a)(1 + p)j/p2]+

で決まります（ω は Teichmüller 指標、C(j, 2) は二項係数）。紙（Hecke の関係式から）。実際の計算は、導手 p2・p3 の指標で捻った L 値から行い、PARI/GP の mspadicseries と 14 組の (E, p) で一致を確かめました。p を法とする上の桁（c2 mod p2、mod p3）は、もう一段深い層の和から同じように取ります。計算（浮動小数・区間演算なし）

03

p = 3 で何が要るか

Ш の p 部分を読む照合（§05）は、計算が一番軽い p = 3 で行いました。連鎖の入力の原典を一つずつ開き、言明の p の範囲を確かめました。既知

  • 判別式の模型。最小でない模型では ordq(Δ) が 12 の倍数だけずれるので、p ≥ 5 では (H) の判定が模型で変わりえます。p = 3 では 12 が 3 の倍数なので変わりません。照合のすべての箱（11,694 箱）で (H) は最小模型の判別式で判定してあり、判定が変わった箱はありません。紙計算
  • Galois 像。p ≥ 5 なら、既約性と (H) から像が SL2(Zp) を含むことが古典的な持ち上げの補題で出て、Kato の言明がそのまま使えます。p = 3 ではその補題が使えないので、Skinner §2.5 の道が実際に要ります。（持ち上げの補題とその番号は記憶によるもので、原典では確かめていません。）

σ 関数の正規化

p 進高さは Mazur–Tate の σ 関数で作ります。その定数 e を、原典（Mazur–Tate–Teitelbaum II §2）は「σ2 の係数が p 進整になる唯一の値」として定め、PARI/GP の文書は s2 = ellpadics2(E, p, n) を「σ が tZp[[t]] に入る唯一の定数」として定めます。二つの微分方程式を並べると e = b2 − 12·s2 で、p = 3 でも p ≥ 5 と同じ正規化です。紙（二つの定義の照合。原典の一意性の証明は先行文献の引用で、追っていません）。曲線 26a1（a3 = 1）で、PARI の高さを使わずに c = s2 から σ を組み立てると t20 まで係数が 3 進整で、s2 + 1/3 や s2 + 3k（k ≤ 3）では整になりません。s2 を 34 を法として定義に当てたことになります。計算（一曲線）

04

予想の桁を数値で照合する

§02 の結論は定理の組み合わせから出るもので、予想は使いません。一方、予想が等式であることは、定理の側からは単数倍までしか見えません。そこで、予想が言う値を p 進の桁ごとに数値と突き合わせました。どの照合も、数える前に規則を固定してから数えています。#Ш の代わりには、複素 BSD 予想が予言する位数

Шan = (L″(E, 1)/2) / (ΩE · ∏cℓ · Reg∞)

を使います（階数 2・自明な捩れ）。Шan は予言値であって、Ш の位数そのものではありません。

最初の桁 (MTT₁) と平方類 (Q)

階数 2・ap = 1・c2 ≢ 0 (mod p) では、εp/p2 ≡ 1・logp(1 + p)/p ≡ 1 (mod p) なので、予想は

c2 ≡ ω · n · #Ш(E/Q) · Regp (mod p) (MTT₁)

を言います。分裂の箱では論文の定理 K から Regp ≡ −B02 · det(χ, γ)2 (mod p)、#Ш は（有限なら）平方数（Cassels）なので、(MTT₁) から

(−c2 · n · ω / p) = +1 (Q)

が従います（左辺は Legendre 記号）。紙（予想からの換算）。(Q) には Ш もレギュレーターも現れません。予想の下で、c2 の平方剰余の類が玉河数の積と判別式の符号だけで決まる、という形です。
