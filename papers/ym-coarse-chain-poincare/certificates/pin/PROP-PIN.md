## 1. 道具（全て標準）

- **(L0) 共役長**［紙］：ε²V″ ≥ −1/8（V″ の最小は z = 0 で −1/2）。両端を固定した n サイトの橋の Φ の Hessian は H₀^{(n)} := tridiag(−1, 15/8, −1) 以上。最小固有値は 15/8 − 2cos(π/(n+1)) で、n = 7 なら 2 − 2cos(π/8) − 1/8 = 0.02724 > 0、n = 8 なら負になる。**7 サイトまでの橋は一様に凸**で、粗い鎖の間隔 8 がちょうどその境にある。箱 K は凸なので、橋の測度は対数凹。
- **(L1) Markov**［紙］：z_1 と z_8 は z_8 を与えると条件つき独立。a は e^{−λ(z_1−a)²/2} だけに入るので、ρ = λCov(z_8, z_1) = λCov(z_8, g(z_8))。ここで g(u) := E[z_1 | z_8 = u] は左の 7 サイトの橋（z_0 = a、z_8 = u）の量である。TP2（第759便の補題 M (b)）により g は増加で、ρ ≥ 0。
- **(L2) Brascamp–Lieb**［既知、凸な定義域でも成り立つ］：Hess(λΦ) ≥ λH₀ の対数凹な測度では Var⟨v,z⟩ ≤ ⟨v, H₀⁻¹v⟩/λ。g′(u) = λCov(z_1, z_7)（橋の中）で、Cov ≥ 0 は FKG による。Cov ≤ Var(z_1+z_7)/4 から
  **g′ ≤ L_g := (h₁₁ + h₇₇ + 2h₁₇)/4 = 1.62695**（hᵢⱼ = (H₀^{(7)})⁻¹ᵢⱼ：h₁₁ = h₇₇ = 2.06960、h₁₇ = 1.18430）。
  よって ρ ≤ λ L_g Var(z_8) ≤ λ L_g E[(z_8 + x_c)²]。
- **(L3) 平均のずれ（部分積分）**［紙、既知の型］：凸でコンパクトな K 上の μ ∝ e^{−λU}、x* を K 上の U の最小点、Y := X − x* とする。div(Y e^{−λU}) を K で積分すると、境界の項 ∫_{∂K}⟨x − x*, ν⟩e^{−λU} が ≥ 0（凸性）になるので、E⟨∇U(X), Y⟩ ≤ n/λ。Hess U ≥ H₀ と一次の最適性 ⟨∇U(x*), Y⟩ ≥ 0 から E⟨Y, H₀Y⟩ ≤ n/λ。⟨Y,H₀Y⟩ ≥ Y₇²/h₇₇ より、
  **E[z₇] ≤ m₇ + √(7h₇₇/λ)**（m₇ は橋の古典的な最小点の z₇。n = 7 の橋）。
- **(L4) 自由エネルギーの微分**［紙］：z_8 の周辺の密度は ∝ e^{−λW(u)}、W′(u) = E[∂_{z_8}Φ | z_8 = u] = 2u − E_L[z_7] − E_R[z_9] + ε²V′(u)。z_8 を与えると、左右は独立な橋になる。端で r = 0 のときは z_9 を b に読み替える。
- **(L5) 比較原理**［既知（Topkis・劣モジュラ）］：Φ の結合 −z_i z_{i+1} は劣モジュラで、橋は狭義凸なので、古典的な最小点は境界値について単調に増える。よって m₇ は a = 0 で、m₉ は内部では b = 0、端では b = −x_c で最大になる。端の右の橋は r ≤ 7 サイトで、(H₀^{(r)})⁻¹ の対角は r について増えるので、r = 7 の評価で足りる。

## 2. 組み立て

(L3) を左右に適用し、(L5) で最悪の幾何に置くと、W′(u) ≥ D(u) − 2e、e := √(7h₇₇·εħ)、D(u) := 2u − m₇(u) − m₉(u) + ε²V′(u)（a = 0・b = 0 の古典の力）。

- u ∈ [−x_c, −0.8] では D ≥ D₀ = 0.023126（§3、区間演算の下界）なので W′ ≥ d := D₀ − 2e > 0。この区間の上の条件つきの法則は、比 e^{−λ(W−W₀)}/e^{−λd(u+x_c)} が減少するので、率 λd の指数分布に確率的に支配される。よって二次の積率は ≤ 2/(λd)²。
- u ≥ −0.8 では W(u) − W(−x_c) ≥ Δ := min_{u≥−0.8} ∫_{−x_c}^{u}(D − 2e) ≥ 0.0041（ħ = 10⁻⁵）。正規化は W′ ≤ M = 2 から ≥ (1 − e^{−λMt})/(λM) で、裾は ≤ x_c³·λM·e^{−λΔ}。λΔ ≥ 819 なので、裾は数値上 0 である。
- 合わせると **ρ ≤ λL_g[2/(λd)² + 裾] = 2L_g εħ/d² + …**。

## 4. 見えたこと（「一点」の形）

- 一つのサイトの曲率は頂上で 15/4 と 4 に 1/4 足りず、各点の判定は全て外れる。それでも縮みが出るのは、**悪い領域を通る長さが共役長より短い**からである（(L0)：7 サイトの橋は凸、8 サイトでは凸でない）。粗い鎖の間隔 8 は、悪い部分を橋の中に閉じ込めて、橋ごとに凸性を回復する長さになっている。
- 小さい ħ の端で効いているのは、凸な橋（L0）と壁への貼り付き（L4 の D₀ > 0）の組み合わせである。最悪の場合の積み上げではなく、「凸な長さで区切り、区切り目で一つの数（ここでは D₀）を見る」という形をしている。① の多段（平均のブロック化の sup μ）にこの形の類比があるかは未検討［読］。
